# Universal Fee Update

- Mandatory application/platform maintenance fee for every tender application.
- Default and current demo amount: ₹2,500 per application.
- Non-refundable.
- Enforced server-side regardless of tender flags or legacy database values.
- Razorpay payment verification remains server-side.
- EMD/Bid Security remains independent and tender-specific.
- Admin-created/updated tenders are automatically normalized to the universal fee.
- All seeded tenders are normalized to ₹2,500 application fee.
- Hubli/Belagavi sealed-vs-unsealed behavior is unchanged.
